# 课程 Deadline 哨兵（Deadline Sentinel）

把课程群导出的聊天记录，整理成**可信、可修改、可导出**的课程待办清单，
减少遗漏作业和截止日期。

面向"大学生 AI Agent 社团招新"的完整作品：**能实际运行、现场演示、讲得清楚**，
不是静态页面或概念原型。

- **规则优先**：核心识别全部是写死的规则，可解释、可复现、零费用。
- **AI 可选**：配置 OpenAI 兼容 API 后，可让大模型补判"规则搞不定的模糊表达"。
  未配置时程序完整可用。
- **几乎零依赖**：仅 Excel 导出需要 `openpyxl`；网页用标准库 `http.server`，AI 用标准库 `urllib`。不装 `openpyxl` 也能正常分析、展示、导出 CSV/JSON。

```powershell

pip install -r requirements.txt        # 仅 Excel 导出需要 openpyxl
```

## 功能

**分析流程**：聊天记录 → 解析消息 → 规则挑任务 → 解析截止时间 → 组装/去重/更正 → 待办清单。

- 网页支持：粘贴、上传 TXT、载入示例、清空；分析时显示加载状态与错误提示。
- 顶部统计：任务总数 / 紧急 / 即将截止 / 待确认。
- 待办列表：任务名、课程群、截止时间、剩余时间、状态、原始消息依据。
- 交互：搜索、按状态/课程群筛选、按截止/紧急/课程群/待确认排序；标记完成、修改、排除误识别。
- 导出：**Excel（.xlsx，推荐）**、CSV（带 UTF-8 BOM，Excel 不乱码）、JSON（含来源与可信度字段，可用于追溯）。
- Excel 导出含：加粗着色的表头、冻结首行、自动筛选、按内容设置列宽，长文本自动换行。
- 空状态 / 异常状态 / 操作反馈齐全。
- **结果全部来自真实输入与真实处理逻辑**，没有内置的假演示数据。

**规则引擎**（`sentinel/`）：

| 模块 | 作用 |
| --- | --- |
| `read_chat.py` | 读 txt → 消息 list；**逐行报告无法识别的原因** |
| `extract.py` | 关键词规则挑任务；主题抽取；置信度；含糊标记 |
| `ddl.py` | 解析绝对/相对日期与时间点；区分"原文明确"与"程序推断" |
| `tasks.py` | 组装任务、去重、更正作废、待确认判定、稳定 ID |
| `report.py` | 命令行文本报告 |
| `export.py` | CSV（带 BOM）/ JSON / XLSX 导出 |
| `ai_helper.py` | 可选 AI 增强（OpenAI 兼容） |

规则要点：
- 任务词：`交 / 提交 / 截止 / 作业 / 实验 / 报告 / 小测 / 考试 / 报名 / 选题 / 答辩 / 论文 / 课设 …`
- 噪音词：`广告 / 收到 / 谢谢 / 怎么 / ？ / 在线等 …`（命中即丢弃）
- 时间：`10月20日`、`2026-11-06`、`今天/明天/后天/N天后`、`本周五/下周日`、`月底前`、`23:59`、`晚上12点`
- 没说时间默认 `23:59`；只写月日且今年已过 → 当作明年（并标"含糊"）。
- 更正：出现"以……为准"时，同群、同主题、更早的任务标为**已作废**。
- 没有日期信息时**保留未知**，绝不编造日期。

## AI 增强（可选）

使用 **OpenAI 兼容接口**，因此可以对接你的 OpenRouter 中转。

### 配置

复制 `.env.example` 为 `.env`，填入：

```dotenv
BASE_URL=https://openrouter.ai/api/v1
API_KEY=sk-你的key
MODEL=openai/gpt-4o-mini
```

或用环境变量直接设置同名变量。启动脚本 `run.ps1` 会自动读取 `.env`。

**安全约定（重要）**：
- **绝不把 API Key 写进源码、网页、日志、README、测试数据或提交到 Git**。
- `.gitignore` 已忽略 `.env`；请只把 `.env.example`（示例值）提交。
- 密钥仅从环境变量/`.env` 读取；网页只显示掩码（如 `sk-1******ab`）。

### 触发条件与成本控制

- **按需触发**：只有勾选"启用 AI 增强"（或 CLI 加 `--ai`）才调用。
- **只发必要的**：仅把"规则不确定"的消息（未知截止时间 / 含糊 / 待确认）发给模型，
  并附最少上下文（群名、消息时间）。**不发送完整聊天记录**。
- **调用上限**：单次分析最多 `MAX_AI_CALLS=5` 条候选（在 `webapp.py` 中可调）。
- **不重复请求**：一次分析只发一批；规则能处理的绝不调用模型。
- **必须校验**：AI 结果经过结构校验（合法 JSON、id 必须来自本次输入、日期可解析且在合理范围），
  校验不过一律丢弃。
- **标记为推断**：AI 给的截止时间标为「AI 推断」并强制进入"建议确认"，不会冒充原文。
- **不覆盖原文**：原始消息、来源始终保留。
- **失败不影响主流程**：超时 / 网络 / 限流 / 无效响应 / 余额不足都会降级为"AI 不可用"，
  继续展示规则结果。

### 关闭 AI

- 网页：不勾选"启用 AI 增强"。
- 命令行：不加 `--ai`。
- 彻底关闭：不设置 `API_KEY`（程序自动进入纯规则模式）。

### 成本说明

本项目**不保证零费用**。费用取决于你所用的中转服务、模型和调用量。
本程序只做了"按需触发 + 限制条数 + 只发必要片段"的节流，无法替你控制中转商计费。

## 隐私与安全边界

- 默认只监听 `127.0.0.1`（本机回环），不开放到局域网/公网。
- 不需要注册，不使用数据库或云服务。
- 不把聊天记录或 API Key 写入日志文件；控制台不打印聊天内容。
- 请求体上限 1MB；网页上传仅接受 `.txt` 且限制大小。
- 不配置 API Key 时，**不会有任何数据外发**。
- 启用 AI 时，网页会明确提示"发送了多少条、发送范围是什么"。

## Agent 架构（v2）

本项目是一个 **AI Agent**，而不是"关键词 + 一次 AI 调用"：

```
用户输入
   ↓
Agent 控制层（sentinel/agent.py）—— 判断是否需要 AI、调度工具、处理歧义、记录过程
   ↓
Tools 工具层
   1. read_chat.py      读文件、拆消息
   2. extract.py        发现作业 / 考试 / 报告 / DDL
   3. ddl.py            日期转换
   4. tasks.py          优先级排序 + 更正 / 去重
   5. context_tool.py   上下文检索（消息看不懂时找附近相关消息）
   6. uncertainty.py    不确定性检测（信息够不够 / 要不要 AI / 要不要确认）
   ↓
LLM（仅在需要时，按模式调用）
   ↓
结果输出（任务清单 + Agent 过程 Trace）
```

Agent 的决策逻辑：
- 规则能确定的（明确日期、固定格式）**绝不调用 AI**；
- 规则搞不定的（无时间 / 含糊 / 疑似更正）才交给 AI，并附带**必要上下文**；
- AI 结果一律标记为「AI 推断 · 需确认」，**不覆盖原文、不伪造来源**；
- AI 失败（超时 / 网络 / 限流 / 余额不足）自动回退规则结果，不影响使用。

网页会展示 **分析过程 Trace**（读取记录 → 发现候选 → 解析时间 → 检测歧义 → 调用 AI → 出结果），
让人看到"这是 Agent 在一步步调用工具"。

### 三种 API 模式

在网页右上角 **⚙ 设置 · AI 配置** 里选择（无需改代码、无需碰 .env）：

| 模式 | 说明 | 需要配置 |
| --- | --- | --- |
| **离线模式** | 只用规则工具，免费、可离线 | 无 |
| **项目演示 API** | 作者预设的演示接口，供他人快速体验 | 由部署者用 `DEMO_BASE_URL/API_KEY/MODEL` 环境变量提供 |
| **我的 API** | 你自己的 OpenAI 兼容接口（OpenRouter / DeepSeek / 任意兼容） | 网页填 Base URL / Key / Model |

**安全（按访客隔离）**：公网部署时，「我的 API」的配置只存在**访客自己的浏览器**
（localStorage），随请求带上、用完即弃；**服务端不保存、也看不到任何访客的 Key**，
访客之间互不干扰（A 填的 Key 不会给 B 用）。页面只显示脱敏 Key（如 `sk-u******56`）。
演示 API 的 Key 只从环境变量读取，绝不进源码或仓库。
默认是**离线模式**，只有你主动选择才会调用 AI。
> 想更换自己的 Key：在浏览器设置里清除本站 localStorage，或点「设置」重填即可。

## 聊天记录格式

每行一条消息，`时间 | 发送人 | 群名 | 内容`：

```
2026-10-14 09:12 | 助教-李 | 数据结构-2026秋 | 实验三报告下周日晚上12点前交，迟交扣20%
```

- 分隔符兼容全角 `｜`；时间支持 `2026-10-14 09:12` 等几种写法。
- 格式不对的行会在网页与报告中**明确提示"第几行、为什么"**，不会静默丢弃。
- 这**不是**直接解析微信原生导出文件，需先把记录整理成上面的格式。

## 已知局限（诚实说明）

- 规则法**会漏、会错**，遇到没见过的说法需手动补关键词。
- 只支持约定的 `|` 分隔格式，不是微信原生导出文件。
- 只写月日（如"3月5日"）的时间按"最近一次"猜，可能不准（会标"含糊"）。
- 时区：消息时间与"现在"都按本机本地时间处理，**不解析时区后缀**（如 `+08:00`），
  也不做夏令时换算。
- AI 增强需要自备 API Key；未配置时该功能不可用（但不影响主功能）。
- AI 判断可能出错，务必以原文与教务系统为准。

## 常见故障

| 现象 | 处理 |
| --- | --- |
| 终端中文乱码 | 先执行 `$env:PYTHONIOENCODING="utf-8"` |
| 端口 8000 被占用 | 改 `webapp.py` 里的 `PORT`，或关掉占用程序 |
| AI 提示"未配置" | 检查 `BASE_URL` / `API_KEY` / `MODEL` 三项是否都设置 |
| AI 提示"鉴权失败" | API Key 错误或过期 |
| AI 提示"限流/余额不足" | 属中转服务侧限制，稍后重试或更换服务 |
| 网页打不开 | 确认服务已启动、地址是 `http://127.0.0.1:8000` |
| 导出 Excel 提示未安装 openpyxl | 运行 `pip install openpyxl`，或改用 CSV 导出 |
| 导出的 CSV 在 Excel 里中文乱码（旧版不是本程序产物） | 本程序 CSV 已带 UTF-8 BOM，若仍乱码请改用 Excel(.xlsx) 导出 |
